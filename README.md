# Shelfie [Online Book Store]

## Student Information

ST10519083 Nemaguvhuni Lusani

## Project overview

• Brief History: Shelfie started as a local retail bookstore in Pretoria and is now expanding online to reach more readers across South Africa.

• Mission and vision: Make books accessible to all and be South Africa’s most loved community bookstore.

• Target Audience: Students, professionals, families and book lovers seeking convenient online and in-store shopping.

## Website goals and objectives

Goal: The main goal of Shelfie is to sell books online and in-store, increase monthly sales and provide customers with an easy platform to browse, order and receive books.

KPIs: Website sales, number of orders, site traffic and customer satisfaction ratings will be used to track the success of the website.

## Key Features and Functionality

• Browse different types of books and view book categories and images.

• Contact and enquiry sections for customers who need assistance.

• Google Forms integration on the enquiries page to collect customer enquiries.

• Contact form with input fields for customer details, message type and message content.

• FormSubmit integration to allow contact form submissions to be sent to the designated email address.

• Easy navigation between the Home, About Us, Services, Contact Us and Enquiries pages.

• Responsive design for different screen sizes and devices.

• JavaScript image gallery functionality that allows users to click on images to view them in a larger lightbox.

• Service search functionality that allows users to search for services using keywords.

• Interactive map controls that allow users to navigate to the Pretoria and Cape Town map locations.

• Form validation using HTML input requirements, including required fields, email format and message length restrictions.

• SEO improvements, including descriptive page titles, meta descriptions, image alternative text and a logical heading structure.

• Internal links between website pages to improve navigation.

• The sitemap and robots file need to be updated with the correct public website URL after deployment.
